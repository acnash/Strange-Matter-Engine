# TDO-CIA-EA-CV-CYP-GCA v1 production campaign

This campaign augments the trajectory fingerprint with two explicit nonlinear
dynamical observables. Net state displacement measures how far the molecular
Graph-CA travels from its learned initial condition. Lag-one temporal
correlation measures whether successive generations persist, reverse, or
oscillate. The differentiable ridge readout receives these observables beside
the established final-state, temporal, multiscale, and state-change-energy
summaries.

Screening compares the established core fingerprint with the dynamic-observable
fingerprint for the leading credible-interval-aligned candidates. Atoms remain
cells, typed bonds define local interactions, and every candidate retains
explicit recurrent generations, backpropagation, differentiable ridge
regression, scaffold-safe selection, sealed evaluation, and blind-label
exclusion. CIA-EA-CV-CYP-GCA is the comparison leader at point MA-ST-RAE
0.748490 and RMSE 0.847738 pIC50.
