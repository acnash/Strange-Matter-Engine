# CYP Dynamics Atlas

Competition workspace for the 2026 marimo and OpenADMET cheminformatics notebook competition.

## Scientific question

Do learned molecular graph dynamics reveal CYP-selective chemistry beyond conventional molecular structure?

## Submission design

- A marimo notebook stored as ordinary Python and hosted on Molab.
- A compact, public data bundle derived from released OpenADMET training data and reproducible Strange Matter Engine analyses.
- Instant interactive exploration backed by precomputed trajectories.
- Optional GPU recomputation for selected examples.
- Clear separation between learned graph-state dynamics and physical molecular dynamics.

## Working files

- `cyp_dynamics_atlas.py`: runnable marimo application.
- `data/`: compact competition-specific tables and trajectory examples.
- `assets/`: portable notebook images and media.

The Molab workspace is named **CYP Dynamics Atlas**.
