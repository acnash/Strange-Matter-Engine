# Scientific Visualisation

## Purpose

Visualisation is a scientific output of Strange Matter Engine. Images and animations should reveal mathematical quantities that the model genuinely produces or uses, making its temporal behaviour easier to inspect and explain.

## Planned views

- **Evolving molecular graph:** fixed molecular connectivity with node colour, size, or glow representing selected state channels.
- **Molecular spacetime:** successive graph states stacked through a temporal dimension so each atom traces a path through time.
- **Oscillator view:** repeating temporal bands or state patterns for periodic trajectories.
- **Propagating excitation:** local changes moving through bonded molecular neighbourhoods.
- **State-space portrait:** a labelled 2D or 3D projection of the high-dimensional global trajectory.
- **Perturbation view:** paired trajectories from nearly identical initial states, showing their divergence or convergence.
- **Attractor atlas:** dynamical fingerprints across many molecules, coloured by experimental `pIC50`, CYP identity, or carefully defined dynamical family.

## Scientific discipline

A projection is not the full state space and must be labelled as a projection. Decorative complexity must not be mistaken for dynamical complexity. Colours, coordinates, distances, and derived quantities should have documented meanings.

## Topics to develop

- visual encodings and perceptual colour scales;
- graph layout consistency through time;
- animation and small multiples;
- dimensionality-reduction methods and their distortions;
- uncertainty visualisation; and
- reproducible figure generation.
